# API de Anúncios em Parceria

Os anúncios de conteúdo de marca agora são chamados de anúncios em parceria.

Os anúncios em parceria permitem que os anunciantes veiculem publicidade de um criador de conteúdo ou de outro parceiro para ampliar as colaborações. Usar a voz de um criador de conteúdo com anúncios em parceria é a melhor forma de gerar alto desempenho nas nossas plataformas.

Nestes tópicos, abordamos como utilizar nossa API para automatizar as funcionalidades e permissões da campanha de anúncios em parceria. Para usar este guia, pressupomos que você já tenha uma empresa, um criador de conteúdo e um plano de mídia para os dois. Ele fornecerá orientações sobre as etapas técnicas de configuração de permissões para que você possa promover essas publicações via API.

A API de Permissões no Nível da Publicação permite que as marcas adicionem, removam e verifiquem os criadores de conteúdo que estão na lista de aprovação para marcá-los na tag de parceria paga em publicações de conteúdo de marca. Também possibilita que os criadores de conteúdo concedam permissão às empresas para promover as respectivas publicações de conteúdo de marca orgânico como anúncios em parceria.

A API de Permissões no Nível da Conta permite que as marcas solicitem permissão de anúncios em parceria aos criadores de conteúdo e validem o status dessas solicitações. Com essas permissões, os anunciantes podem promover o conteúdo do criador que os marca em publicações usando uma tag de parceria paga ou em outro conteúdo sem marca (@menções, tags de pessoas, tags de produtos ou publicações de collabs do Instagram). Eles também podem criar novos anúncios em parceria que não tenham uma publicação orgânica existente sem atribuir permissões no nível da publicação.
