# Recursos

Lista dos recursos possíveis de uma conta de anúncios. Faça uma chamada HTTP GET ao ponto de extremidade `act_{AD_ACCOUNT_ID}?fields=capabilities` para obter todos os recursos.

**Observação**: esse ponto de extremidade permanece acessível para fins herdados. Apesar de oferecer funcionalidades além das listadas nesta página, a maioria é voltada para uso interno. _Evite o uso desse ponto de extremidade e não confie nos respectivos resultados no seu programa._ Eventualmente, esse ponto de extremidade será eliminado.

Recurso

Descrição

CAN\_USE\_REACH\_AND\_FREQUENCY

A capacidade de comprar [anúncios de alcance e frequência](/docs/marketing-api/reachandfrequency/).

DIRECT\_SALES

As vendas diretas são contas totalmente gerenciadas por funcionários do Facebook em nome de anunciantes que compraram um pedido de inserção.

VIEW\_TAGS

A capacidade de rastrear impressões por meio de tags de visualização de terceiros.
