# Ad Account Minimum Budgets

[](#)

## Leitura

The minimum daily budget value for an ad set in an Auction campaign, given the bid\_amount if use manual bid

### Parâmetros

Parâmetro

Descrição

`bid_amount`

integer

Provide this value if you want to get values for manual bid.

### Campos

A leitura desta borda retornará um resultado formatado em JSON:

```

```
