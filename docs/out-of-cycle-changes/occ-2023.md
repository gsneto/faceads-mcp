# Alterações fora de ciclo de 2023 Alterações fora de ciclo da API de Marketing em 2023.

## 6 de junho de 2023

### API de Anúncios do Instagram #### Posicionamento da aba Loja do Instagram O posicionamento de anúncios na aba Loja do Instagram (`“instagram_positions”: [“shop”]`) não está mais disponível para novas campanhas de anúncios. Essa mudança afeta os seguintes pontos de extremidade ao criar anúncios: \* [POST /{ad-accout-id}/adsets](/docs/marketing-api/reference/ad-campaign) \* [POST /ad\_set\_id](/docs/marketing-api/reference/ad-campaign) \* [GET /{ad-id}/previews](/docs/marketing-api/generatepreview) \* [GET /{ad-account-id}/generatepreviews](/docs/marketing-api/generatepreview)
