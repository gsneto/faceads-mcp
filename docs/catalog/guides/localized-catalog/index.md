# Catálogos localizados

## Visão geral

Seu [catálogo](/docs/marketing-api/catalog) é um objeto (ou contêiner) de informações sobre seus produtos e onde você deve adicionar seu estoque.

A Meta oferece o recurso de catálogo localizado para que você possa promover itens em anúncios ou lojas para outros países. Localizar a moeda, o preço e o nome ou a descrição são os casos de uso mais comuns. É possível também criar um URL localizado para o produto para levar o cliente até o site específico do país ou idioma
