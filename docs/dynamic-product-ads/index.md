# Anúncios de Catálogo Advantage+

Com os [Anúncios de Catálogo Advantage+](https://www.facebook.com/business/a/online-sales/dynamic-product-ads), é possível promover itens relevantes de um catálogo em qualquer dispositivo. Mostre anúncios de milhares de itens para o público certo e automatize o processo. Essa solução tem três elementos principais:

![](https://scontent.fcpq7-1.fna.fbcdn.net/v/t39.2365-6/23204403_493201307718997_4485178727386316800_n.png?_nc_cat=108&ccb=1-7&_nc_sid=e280be&_nc_ohc=W0smdcPR3LgQ7kNvwHZQNzg&_nc_oc=AdkZrvi-7zZ0nXo_50Cn4MmUCtKuPAIecWflmYDSIAkZs-4_tFogSMs-wJIlBtEklGO4uLkEm_9oxuCh5rm6baXj&_nc_zt=14&_nc_ht=scontent.fcpq7-1.fna&_nc_gid=su99rTHl7jq_g6YABqR8sA&oh=00_AftGily5kz5I_IPxYMsrOq5xfZ5VIceTidi6Ps5nO_os0g&oe=6999B48D)

1.  [Criação de um feed para o catálogo](/docs/marketing-api/catalog) a fim de veicular imagens, descrições e preços nos anúncios de forma automática.
2.  Configuração de [Eventos do App](/docs/app-events) ou do [Pixel da Meta](/docs/meta-pixel) para mensurar ações (como compras) e definir o perfil dos [públicos-alvo](/docs/marketing-api/audiences/guides/dynamic-product-audiences) de um anúncio.
3.  [Criação e veiculação de anúncios com base no seu catálogo](/docs/marketing-api/dynamic-ads/get-started) para mostrar itens relevantes do feed do catálogo e definir o público-alvo.

Depois de configurar esses elementos, é possível ver como as pessoas no Facebook estão [interagindo com os anúncios](/docs/marketing-api/reference/adgroup/insights/), bem como usar [ferramentas de depuração](/docs/marketing-api/dynamic-product-ads/debugging-tools) para diagnosticar e resolver problemas.
