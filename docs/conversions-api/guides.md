# Guias

Use estes guias se precisar de ajuda para realizar ações comuns com a API de Conversões.

### [Enviar solicitações e verificar eventos](/docs/marketing-api/server-side-api/using-the-api#send)

Saiba como enviar eventos para a API de Conversões, gerenciar eventos perdidos e solicitações em lote e confirmar que seus eventos chegaram.

### [Configurar a API de Conversões como uma plataforma](/docs/marketing-api/server-side-api/set-up-server-side-as-a-platform)

Caso você ofereça o Pixel da Meta aos seus clientes, considere adicionar funcionalidades da API de Conversões. Saiba como configurar nossos eventos de servidor como parte da sua plataforma.

### [Integração via Zapier](/docs/marketing-api/server-side-api/guides/zapier-integration)

Você pode usar a plataforma de automação Zapier para enviar eventos à nossa API de Conversões. Use o app Zapier do Facebook para enviar eventos automaticamente sempre que houver alterações na sua fonte de dados.

### [API de Conversões para o Gerenciador de tags do Google](/docs/marketing-api/conversions-api/guides/gtm-server-side)

A API de Conversões pode ser usada para coletar dados importantes de eventos na web e offline que foram compartilhados a partir de um servidor configurado por você no Google Cloud Platform. Saiba como implementar essa funcionalidade.

### [Recursos do SDK de Negócios da Meta para a API de Conversões](/docs/marketing-api/conversions-api/guides/business-sdk-features)

Conheça os recursos avançados do SDK de Negócios da Meta para usuários da API de Conversões: solicitações assíncronas, criação de lotes concorrentes e interface de serviço HTTP.

### [Implementação de ponta a ponta](/docs/marketing-api/conversions-api/guides/end-to-end-implementation)

Confira um guia passo a passo para implementar a API de Conversões. Veja instruções para fazer a integração direta e como uma plataforma.

### [Conversions API Gateway](/docs/marketing-api/conversions-api/guides/gateway)

Confira uma visão geral e um guia passo a passo para configurar e implementar o Conversions API Gateway. Veja também instruções para solução de problemas e monitoramento.

### [Conversions API Gateway: AWS App Runner](/docs/marketing-api/conversions-api/guides/gateway-aws-app-runner)

Consulte o guia passo a passo para implementar a configuração do Gateway da API de Conversões usando o AWS App Runner.

### [Conversions API Gateway para várias contas](/docs/marketing-api/conversions-api/guides/gateway-multiple-accounts)

Confira um guia passo a passo para conectar fontes de dados gerenciadas por diferentes contas comerciais da Meta à mesma instância do Conversions API Gateway.

### [API do Plano de Controle do Conversions API Gateway para várias contas](/docs/marketing-api/conversions-api/guides/gateway-control-plane-api)

Esta API permite que os desenvolvedores gerenciem programaticamente contas, fontes de dados e outras configurações de uma instância do Gateway.
