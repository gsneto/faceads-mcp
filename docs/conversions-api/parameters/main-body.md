# Parâmetros de corpo principal

Parâmetro

Descrição

[`data`](#)

array<object>

**Obrigatório.**  
Uma matriz de objetos de eventos do servidor. Consulte [Parâmetros de evento do servidor](/docs/marketing-api/server-side-api/parameters/server-event) para mais informações.

[`test_event_code`](#)

string

**Opcional.**  
O código usado para verificar se os eventos do seu servidor são recebidos corretamente pelo Facebook. Use esse código para testar seus eventos do servidor com o recurso Eventos de Teste no Gerenciador de Eventos. Consulte [Ferramenta Eventos de Teste](/docs/marketing-api/facebook-pixel/server-side-api/using-the-api#testEvents) para ver um exemplo.
