# Alterações fora de ciclo

As alterações fora de ciclo são mudanças realizadas fora de um lançamento-padrão com controle de versão. Normalmente, essas alterações afetam todas as versões de API no momento em que são lançadas. Essas alterações estão registradas abaixo, de acordo com a data de lançamento.
