# Prévias do anúncio

Veja uma prévia dos anúncios existentes e gere prévias dos que você quer criar. A prévias geradas têm como base o seu criativo do anúncio. Para a pré-visualização do anúncio, **forneça um token de acesso do usuário** em vez de um token de acesso à Página. Por exemplo, veja a prévia de um criativo do anúncio existente:

```
v24.0
```

Ou gere uma prévia usando especificações do criativo de um anúncio de domínio para um site externo:

```
v24.0
```

[](#)

## Geração de prévias

Há algumas formas de gerar uma prévia:

-   Usando a identificação do [anúncio](/docs/reference/ads-api/adgroup/)
    
-   Usando a identificação do [criativo do anúncio](/docs/reference/ads-api/adcreative/)
    
-   Informando as especificações do criativo
    

Para usar o ID de um anúncio existente, use [`previews`](/docs/marketing-api/reference/adgroup/previews) do anúncio.

```
https://graph.facebook.com/<API_VERSION>/<AD_ID>/previews
```

Para usar o ID de um criativo do anúncio existente, use [`previews`](/docs/marketing-api/reference/ad-creative/previews) do criativo.

```
https://graph.facebook.com/<API_VERSION>/<AD_CREATIVE_ID>/previews
```

Para usar uma [especificação do criativo do anúncio](/docs/reference/ads-api/adcreative/), use uma destas duas opções de ponto de extremidade:

-   [`/act_<AD_ACCOUNT_ID>/generatepreviews`](/docs/marketing-api/reference/ad-account/generatepreviews/) ou
    
-   [`/generatepreviews`](/docs/graph-api/reference/generatepreviews/) – o criativo passado na chamada não deve ser associado a uma conta de anúncios específica.
    

Para os Anúncios de Catálogo Advantage+, passe object\_story\_spec para o ponto de extremidade /generatepreviews. Além disso, use `product_item_ids` descrito em [Advantage+ Catalog Ads, Preview](/docs/marketing-api/dynamic-product-ads/ads-management#dynamicpreview).

As prévias de uma conta de anúncios são visíveis apenas para as pessoas que têm uma função na conta. Já as prévias geradas usando a borda `generatepreviews` são visíveis para qualquer pessoa.

```
https://graph.facebook.com/API_VERSION>/act_<AD_ACCOUNT_ID>/generatepreviews
https://graph.facebook.com/API_VERSION>/generatepreviews
```

Todos os quatro pontos de extremidade acima retornarão um [objeto de prévia do anúncio](/docs/marketing-api/reference/ad-preview/).

## Exemplos

Crie uma prévia usando `object_story_spec`:

```
v24.0
```

Crie uma prévia de anúncio multiproduto usando `object_story_id`. Para obter `object_story_id`, primeiro é necessário criar um [anúncio multiproduto](/docs/reference/ads-api/multi-product-ads).

```
v24.0
```

Crie uma prévia do anúncio de app usando `object_story_spec`. Essa é a única forma de gerar a prévia de um anúncio de app.

```
v24.0
```
