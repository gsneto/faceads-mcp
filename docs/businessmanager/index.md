# API do Gerenciador de Negócios

Ajude empresas e agências a gerenciar Páginas do Facebook, contas de anúncios e apps em um só lugar. Com a API do Gerenciador de Negócios, você gerencia vários ativos e permissões de contas de anúncios. Também é possível automatizar a criação dessas contas. Consulte [Sobre o Gerenciador de Negócios da Meta](https://www.facebook.com/help/113163272211510/).

No Gerenciador de Negócios, você conecta ativos relacionados a anúncios e outros ativos de negócios para o seguinte:

-   Gerenciar permissões
    
-   Veicular campanhas em nome de outra empresa
    
-   Criar contas de anúncios e atribuir créditos para compra de anúncios
